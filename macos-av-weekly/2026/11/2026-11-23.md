# macOS 音视频开发技术周报 第5期
2026-11-23｜统计周期：11月16–22日

> 历史归档整理版，保留八项主题、数据、技术分析及原始 PR 链接，非逐字原文。所有 PR 均为已提交提案，未独立核实合并状态。性能数据来自作者，未经独立复测。

## 1. VideoToolbox Full Range 修复
11月19日，#26200。videotoolboxenc.c 对 AV_PIX_FMT_VIDEOTOOLBOX 输入未创建源图像缓冲区属性，即使 color_range=AVCOL_RANGE_JPEG，video_full_range_flag 仍可能为0。提案从 sw_pix_fmt 获取软件格式创建 CoreVideo 属性，无法映射时保留默认路径。影响 CVPixelBuffer、AVHWFramesContext 编码色彩正确性。阅读 create_cv_pixel_buffer_info()、vtenc_configure_encoder()，验证实际 VUI。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26200)

## 2. Metal YADIF 每帧单次提交
11月20日，#26244。NV12/P010 两平面由分别提交和等待改为单 Command Buffer/Compute Encoder，参数改用 setBytes 避免覆盖，失败返回 AVERROR_EXTERNAL。作者测试 1080p59.94 单场耗时 M1 2.34→1.86ms（-20.5%），M1 Max 0.81→0.57ms（-29.6%）；NV12/P010、TFF/BFF framemd5 一致。注意 CVMetalTextureRef 生命周期及 GPU 完成时机。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26244)

## 3. Metal BWDIF
11月22日，#26276。bwdif_videotoolbox 将 CPU BWDIF 移植到 Metal Compute，减少硬件帧下载上传。浮点精确范围与 floor() 保持整数算法一致，拒绝超过10-bit格式。作者 M1 Max 1080 两平面纯 Kernel：NV12 BWDIF 0.138ms/YADIF 0.113ms；P010 0.147/0.125ms，非端到端耗时；CPU framemd5 一致。适用于1080i 广播及隔行 MPEG-2/H.264。复用单 Command Buffer，在 config_output 提前拒绝格式。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26276)

## 4. Ogg/NUT Demuxer Flush
11月20日，#26225。avformat_flush() 清理通用 Packet、Parser、时间戳但不一定清理私有状态。NUT 同步点、Ogg Page 可能残留。提案增加内部 FFInputFormat 回调 int (*read_flush)(struct AVFormatContext *s); 并非公开 AVInputFormat API。影响自定义 AVIO、手动定位及断线恢复。Flush 不等同重新打开 Demuxer。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26225)

## 5. MOV/CMAF Open-GOP 时间戳
11月21日，#26262。负 CTS Offset 可能使 Leading Pictures 显示时间早于 tfdt；提案调整初始 Composition Time Shift。延迟轨道由不允许的 Empty Edit 改为 tfdt 与单 Offset Edit。影响 HLS fMP4、CMAF、同步和重封装。检查 DTS、CTS、tfdt、Edit List；作者 h264/twofields_packet.mp4 复现每 Fragment 提前两帧并增加 API 测试。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26262)

## 6. HLS fMP4 初始化段
11月21日，#26253。single_file 与 hls_fmp4_init_resend 组合可能访问空文件名；初始化段写入失败可能被忽略。提案禁止单文件重发，修正错误传播并增加 FATE。影响直播录制和自动化转码。检查 hls_write_init_file()、hls_write_packet()。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26253)

## 7. HTTP Proxy 重连泄漏
11月19日，#26197。407 认证重连失败时，已分配 zlib 状态或重定向地址未释放；URLContext 尚未打开，ffurl_closep() 不会自动调用关闭回调。提案统一跳转清理标签，调用 http_proxy_close()。影响企业代理及频繁重试。URLProtocol 打开失败路径须自行清理部分状态。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26197)

## 8. 多格式内存安全
11月18日，#26181。Michael Niedermayer 五项修复涉及 APV、HEVC CBS、CFHD、RTMP、AV1 RTP。APV Frame Threading 设置后不应继续启动同 Packet 额外 Primary Frame；HEVC SPS 无有效尺寸时限制 Decoding Unit 数量。作者报告自动化扫描及 ASan 复现。检查 cbs_h265_syntax_template.c、apv_decode.c，增加损坏码流回归。
[PR](https://code.ffmpeg.org/FFmpeg/FFmpeg/pulls/26181)
