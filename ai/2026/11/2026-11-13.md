# GitHub AI 开源项目周报 第3期
2026-11-13｜统计周期：11月6–12日

> 历史归档整理版，非逐字原文。七个项目均首次上榜；Star 增量来自原报告第三方趋势快照，未重新核实。

## 1. t3code
[GitHub](https://github.com/pingdotgg/t3code)
七日约 +10,180 Stars（21%）。统一管理 Codex、Claude Code 等本地 Agent 的会话、审批和跨设备交互。区别于 Worktrunk 的工作区隔离及 Orca 的桌面编排，更强调远程控制。已有 Issue/PR 活动，但不能据此判断稳定性。适合多项目和跨设备开发；审查认证、网络暴露、审批及工作目录权限。研究流式事件、会话协议和任务恢复。

## 2. Xinference
[GitHub](https://github.com/xorbitsai/inference) · [v4.2.0](https://github.com/xorbitsai/inference/releases/tag/v4.2.0)
11月7日发布。Xavier Prefix Cache Sharing 在兼容 vLLM、SGLang、TensorRT-LLM、MLX 副本间复用前缀缓存，扩展 LMCache/Mooncake，Agent 等待工具时优先保留相关前缀。新增滚动重载及 TTFT/TPOT 基准。区别于单引擎缓存，关注多副本服务层。正式版本，需验证模型、Tokenizer、位置编码、缓存格式和后端兼容性。适合长 System Prompt、多 Agent、高吞吐服务。

## 3. TensorFold
[GitHub](https://github.com/ashhart/TensorFold)
11月12日进入趋势榜，约1900 Stars，Apache-2.0。Zig 实现模型加载、Tokenizer 和 Metal/CUDA/Vulkan Kernel 执行，减少 Python 依赖。区别于 C/C++ llama.cpp 和 MLX 数组框架。成长型项目，不能据支持 Metal 推断性能优势；实测模型覆盖、量化精度、显存和吞吐。适合 macOS 原生应用和 GPU 研究，关注 Buffer 生命周期、Kernel 调度及权重加载。

## 4. Paperclip
[GitHub](https://github.com/paperclipai/paperclip) · [v2026.1106.0](https://github.com/paperclipai/paperclip/releases/tag/v2026.1106.0)
11月6日版本包含515个提交。Runner 成为符合条件 macOS/Linux 主机新建 Claude、Codex、OpenCode、Pi Agent 默认执行路径，新增 Copilot Harness、仓库 Skill 来源、模型辅助注入防护、OTLP/Braintrust 和加密恢复点。区别于单纯聊天或工作区工具，强调生命周期、授权、审计。适合团队长期任务；关注兼容性变化，模型检测不能替代强制权限隔离。

## 5. OpenMausBot
[GitHub](https://github.com/milind-soni/OpenMausBot)
七日约 +8434 Stars，Apache-2.0。自托管多 Bot 平台，提供虚拟机执行环境、工具及聊天交互。区别于仅提供工具接口的框架。适合隔离任务和实验性助手；独立审计网络、挂载、宿主机凭据及隔离强度。研究消息协议、工具结果、资源限制和中断恢复。

## 6. Astryx
[GitHub](https://github.com/meta/astryx) · [项目网站](https://astryx.atmeta.com)
七日约 +12467 Stars，MIT。面向 Agent 的可定制设计系统，通过组件与设计约束降低生成 UI 风格漂移。区别于传统手动组件库，强调机器理解组件用途及组合规则。适合 Web UI、内部工具和原型；验证框架兼容、无障碍、主题与 API 稳定性，热度不代表成熟。

## 7. LLM Router
[GitHub](https://github.com/sockless-coding/llm-router) · [Releases](https://github.com/sockless-coding/llm-router/releases)
11月8日发布2026.11.0。LR.Agent 让远程 Windows/Linux 节点经 WebSocket 主动连接路由器，支持 NAT 后节点，新增 vLLM、模型分类和决策接口。区别于 Xinference 的缓存优化，更侧重多机器接入与路由。适合团队 GPU 池；审查认证、加密、升级及安装脚本。研究节点注册、能力发现和健康检查。

## 趋势与建议
Agent 控制平面逐渐独立；推理优化扩展到跨副本缓存及调度；原生推理出现 Zig 等新路线。优先研究 TensorFold（Metal 底层）、t3code（Codex 多任务）、Xinference（KV Cache、TTFT/TPOT）。未重复推荐 claude-mem、agent-desktop、Worktrunk、HyperFrames；REA 与 Cloudflare security-audit-skill 未仅凭热度再次上榜。未独立审计全部提交及 PR，成熟度不等同生产可靠性。
